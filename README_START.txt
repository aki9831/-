# Shadow Parkour: Nightfall

## Запуск одной кнопкой в Windows

1. Скачайте репозиторий целиком через Code → Download ZIP.
2. Распакуйте ZIP.
3. Дважды нажмите `START_GAME.bat`.

При первом запуске файл автоматически подготовит локальное окружение и установит pygame. Команды вручную вводить не нужно. Для первого запуска нужен интернет; после установки pygame игра запускается локально.

## Управление

- A/D или стрелки — движение
- SPACE/W — прыжок и двойной прыжок
- F/J — ближняя атака
- K — дальняя атака
- Q — специальная атака героя
- SHIFT — рывок
- CTRL/C — подкат
- I — интерактивный инвентарь
- 1 — лечебное зелье
- 2 — энергия
- 3 — дымовая завеса
- P — пауза
- ESC — назад/выход из меню

## Добавлено

- интерактивный инвентарь прямо во время уровня;
- три типа расходуемых предметов;
- уникальная специальная атака Knight, Ranger и Mage;
- квестовая панель с артефактами, убийствами и боссом;
- награда за выполнение квеста;
- дымовая завеса с временной неуязвимостью;
- однокнопочный запуск для Windows.

`START_GAME.bat` не является скомпилированным EXE: он автоматически запускает игру через Python. Для полностью автономного EXE нужен отдельный процесс сборки PyInstaller на Windows.
